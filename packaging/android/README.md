# 听屿 FM 安卓测试版

独立 Android WebView 容器，Android 8.0+，加载现有 HTTPS 正式网站。不修改苹果项目或服务器网站；保留网页所有现有歌词样式、专辑墙、平台切换和音频流程。

服务器曲库沿用网页邮箱验证码授权：输入自己的邮箱，收取验证码并验证；会话保存在本机 WebView 中。安卓不豁免服务端鉴权。SMTP 密码、邮箱账号密码和服务端签名密钥不进入 APK。清除 App 数据后需要重新验证；不同手机不会自动共享登录会话。

首次显示「天天开心，听歌愉快」，后续联网获取版本公告并单独记录已读。网页更新重新打开即可加载，原生代码更新需要安装新 APK。

构建：JDK 17、Android SDK 35、Gradle 8.11.1，在本目录运行 `gradle :app:assembleDebug :app:lintDebug`。GitHub Actions 的 Android APK 工作流自动构建和验证签名。

本次为 debug 签名测试包，可直接安装，无需苹果签名工具。CI 默认调试签名不能保证后续构建覆盖升级，正式持续分发前需要配置固定的私有发布签名并备份，不能将密钥提交仓库。签名不同需卸载旧测试版，会清除登录数据。

尚待安卓真机测试：邮箱收码验证、各平台登录、文件导入、播放及动画性能。本版沿用网页播放器，尚未实现安卓原生 MediaSessionService；不能保证锁屏或后台持续播放。没有关闭原网页特效来规避性能问题。
